# SaveApp

Приложение для скачивания видео по ссылкам с **YouTube** и **TikTok** прямо на iPhone или iPad. Всё работает внутри приложения — компьютер не нужен. После скачивания видео сохраняется в галерею (Фото).

## Как это устроено

- **YouTube** — используется библиотека [YouTubeKit](https://github.com/alexeichhorn/YouTubeKit): информация о видео и ссылка на поток получаются на устройстве, файл скачивается через приложение.
- **TikTok** — запрос к публичному API (без ключа), получение ссылки на видео без водяного знака, скачивание и сохранение в Фото.

Компьютер и бэкенд не требуются.

## Запуск

1. Откройте `SaveApp.xcodeproj` в Xcode.
2. Выберите симулятор или подключённое устройство.
3. Нажмите Run (▶️).

## Использование

1. Вставьте ссылку на видео (YouTube или TikTok) в поле ввода.
2. Нажмите **«Получить информацию»** — под полем появится превью, название и при наличии — автор и длительность.
3. Нажмите **«Скачать в галерею»** — после загрузки видео сохранится в приложении «Фото».

Поддерживаемые ссылки:

- `youtube.com/watch?v=...`, `youtu.be/...`
- `tiktok.com/@user/video/...`, `vt.tiktok.com/...`

## Требования

- Xcode
- iOS 26.0+ (при необходимости можно понизить deployment target в настройках проекта)

## Структура проекта

- `SaveApp/` — исходный код приложения (SwiftUI):
  - `ContentView.swift` — экран с полем ссылки, информацией о видео и кнопкой скачивания
  - `Models/VideoInfo.swift` — модель данных о видео
  - `Services/DownloadService.swift` — логика для YouTube (YouTubeKit) и TikTok (API)
- `backend/` — ранее использовался для варианта с ПК; для текущей версии не нужен.

## Зависимости

- [YouTubeKit](https://github.com/alexeichhorn/YouTubeKit) (Swift Package) — извлечение потоков и метаданных YouTube на устройстве.
